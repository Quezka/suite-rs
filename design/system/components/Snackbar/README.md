# Snackbar

A short message after an action, with Undo when the action deleted something.

Says what happened in a few words; stays 4 seconds; sits above the tab bar or dock.

The consumer supplies the words (translated) and what happens on press. In code: `quezka_kit::widgets` (Rust), `quezka_ui.widgets` / `settings` (Python), `ui/` (Kotlin).
