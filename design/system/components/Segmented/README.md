# Segmented

Two to four mutually exclusive choices side by side, such as System / Light / Dark.

Use instead of tabs or a drop-down when every choice fits. The chosen one is `accent-soft` with a tick when there's room.

The consumer supplies the words (translated) and what happens on press. In code: `quezka_kit::widgets` (Rust), `quezka_ui.widgets` / `settings` (Python), `ui/` (Kotlin).
