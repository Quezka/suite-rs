# Sidebar

The desktop app's sections, in a floating panel on the left.

Floats `gap` from the window edges with `radius-lg`; items round to radius-lg minus its padding. Glass where the system can blur behind the window.

The consumer supplies the words (translated) and what happens on press. In code: `quezka_kit::widgets` (Rust), `quezka_ui.widgets` / `settings` (Python), `ui/` (Kotlin).
