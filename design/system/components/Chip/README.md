# Chip

Filters and quick picks in a row, such as a note's notebook filters.

Pills with `label` type; the chosen one is tonal. Rows of chips scroll sideways, never wrap into a block.

The consumer supplies the words (translated) and what happens on press. In code: `quezka_kit::widgets` (Rust), `quezka_ui.widgets` / `settings` (Python), `ui/` (Kotlin).
